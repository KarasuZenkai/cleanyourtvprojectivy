# Listas de referencia de otros televisores

Este directorio conserva listas de debloat aportadas al [proyecto original CleanYourTV, de Gathin23](https://github.com/Gathin23/cleanyourtv/tree/main/examples). Son datos históricos de modelos y firmwares específicos. Algunas notas dentro de los archivos mencionan el launcher original porque describen pruebas realizadas antes de crear este fork.

**Ninguna de estas listas documenta las TCL 75A400 Pro y 43Q5K comprobadas en este proyecto.** Incluso las listas de otros equipos con dispositivo `G10` no validan la 43Q5K ni el cambio a Projectivy. No apliques una lista por compartir marca, placa o versión de Android. Revisa cada paquete de tu televisor y conserva TV en vivo, HDMI, controles, red y actualizaciones según tus necesidades.

Para cambiar únicamente el HOME a Projectivy, sigue el [procedimiento principal](../README.md); no necesitas ejecutar una lista de este directorio. Si decides hacer debloat por separado, usa el script reversible de [desactivación](../tools/disable.sh) y su [restauración](../tools/restore.sh), y guarda el archivo de recuperación.
