# Código de conducta

Este fork parte del trabajo comunitario de [CleanYourTV, de Gathin23](https://github.com/Gathin23/cleanyourtv). Conservamos el trato respetuoso y la precisión técnica.

- Trata con respeto a quienes reporten fallos o compartan experiencias en otros modelos.
- Describe lo que comprobaste: modelo, firmware, comandos y resultado.
- No publiques datos privados de otras personas, identificadores de dispositivos, nombres de redes, IP ni claves ADB.
- Reconoce el código, las capturas y el trabajo de Gathin23 y Spocky cuando corresponda.
- No propongas instrucciones destinadas a dañar una TV o acceder a un dispositivo ajeno.

Quienes mantengan este fork podrán ocultar contenido o bloquear cuentas que incumplan estas reglas. Para vulnerabilidades, consulta [SECURITY.md](SECURITY.md).
